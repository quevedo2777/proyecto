# Proyecto Películas

En este proyecto se completa una estructura para que los archivos con los códigos funcionen simultáneamente.

## Requisitos
* Python 3.14.3

## Instalación

1. **Clonar el repo:**
   `git clone URL_DEL_REPO`

2. **Instalar dependencias:**
   `pip install -r requirements.txt`
