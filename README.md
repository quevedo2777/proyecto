#Proyecto peliculas
en este proyecto se completa una estructura para que los archivos con los codigos funcionen simultaneamente
##Requisitos
Python 3.14.3
##Instalación
1. Clonar el repo: `git clone URL_DEL_REPO`
2. Instalar: `npm install` o `pip install -r requirements.txt`
